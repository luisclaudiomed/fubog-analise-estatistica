# Versionamento científico

1. Preservar cada edição em diretório separado.
2. Só declarar fase concluída após auditoria e documentação de evidência.
3. Nunca inventar hashes de documentos externos não arquivados.
4. Não publicar dados identificáveis de candidatos, pacientes ou credenciais.
5. Distinguir inscrições, presentes, convocados e matriculados.
6. Commits no GitHub não são automáticos: cada atualização deve ser enviada e verificada.
7. **Repositório inicialmente público**: não incluir bases sensíveis até alteração para privado.
