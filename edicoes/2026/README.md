## Limites científicos
As 305 pessoas publicadas não equivalem às 354 inscrições nem ao número de presentes (desconhecido). O relatório de notas **não tem caráter classificatório**. Não há matriz de respostas candidato×item, enunciados oficiais completos, gabarito definitivo consolidado nem certeza de todos os vínculos entre convocações.

**Atenção ao GitHub público:** este repositório contém apenas código e agregados não identificáveis. A base completa e dados documentais de trabalho permanecem no Deepnote. Não atribuir dificuldade empírica às questões nem probabilidades pessoais a distribuições sintéticas.
