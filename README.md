# FUBOG — análises estatísticas de residência médica

Repositório para organizar estudos históricos de seleções de Oftalmologia por edição, com rastreabilidade dos editais, scripts, cálculos e auditorias.

## Organização

- `edicoes/2024/` — estudo histórico (importação pendente).
- `edicoes/2025/` — estudo histórico (importação pendente).
- `edicoes/2026/` — PSU-GO 2026; documentação e código da Fase C disponíveis no arquivo Git local preparado anteriormente, aguardando importação completa.
- `docs/` — protocolo de versionamento, proveniência e limitações.
- `dados/` — documentação de dados; não publicar arquivos pessoais/identificáveis.
- `scripts/` — scripts transversais.

## Estado do projeto

Este é o **repositório remoto GitHub**. O primeiro commit local da cópia anterior (`0a774a0`) não foi importado como histórico remoto; os commits do GitHub terão SHA próprios. Os estudos e as bases **não são sincronizados automaticamente**.

### Privacidade

**Atenção:** o repositório foi identificado como **público** no GitHub. Por isso, a importação inicial deve conter apenas documentação sem dados pessoais. Antes de adicionar bases, resultados nominais ou arquivos científicos sensíveis, alterar a visibilidade para **Private** nas configurações do GitHub.

Não adicionar senhas, tokens, credenciais ou dados individualizados de candidatos ou pacientes.

## Regra científica

Nunca combinar regras de edições distintas sem verificar o edital correspondente. Simulações sintéticas não devem ser apresentadas como probabilidades reais de aprovação; limitações e pendências documentais devem acompanhar os resultados.
